# 发布步骤（维护者用）

适用版本：**v0.1.2**。面向第一次发布的人，全部在图形界面完成，不需要命令行。
发布前请先确认：DSH 页面刷新后右下角能看到克莱恩猫和蓝色大鱼；点猫能切三态、有声音。
如果看不到猫，先别发布，回聊天里说明现象。

## 0. 先确认本机

1. DSH 页面按 `Ctrl+R` 刷新。
2. 右下角应有猫和 `dsh-pet`（蓝色大鱼）；点猫三次看三态和音效。
3. 如果猫被隐藏：侧边栏底部找猫爪按钮点一下；如果连猫爪都没有，先停下反馈。

## 1. 打开 GitHub Desktop

1. 开始菜单搜 **GitHub Desktop** 并打开。
2. 打不开/提示损坏：双击 `C:\Users\shado\Downloads\GitHubDesktopSetup-x64.exe` 重装，再打开并登录 GitHub。
3. 如果左侧没有项目：`File → Add local repository`，选 `D:\软件\DSH workplace\klein-cat-pet`，点 **Add**。

**你应该看到**：左侧有 `klein-cat-pet`，上方是 `main`。

## 2. 提交并推送

1. 点 **Changes**。应看到 7 个文件：
   - `package.json`
   - `README.md`
   - `CHANGELOG.md`
   - `.github/workflows/release.yml`
   - `.github/workflows/ci.yml`
   - `.gitignore`
   - `docs/发布步骤.md`（新增）
2. 如果看到 `dist/`、`art.json`、`tools/preview.html`，不要勾选（它们已被忽略，正常不会出现）。
3. 左下角 Summary 填：
   `chore(release): v0.1.2 — tgz 发行包与安装文档修复`
4. 点 **Commit to main**。
5. 点上方 **Push origin**。

**你应该看到**：Changes 变成 0；Push origin 不再有未推送提示。

## 3. 在 GitHub 网页发布 v0.1.2

1. 浏览器打开 `https://github.com/BeyondGu/klein-cat-pet`（保持登录）。
2. 点 **Releases → Draft a new release**。
3. **Choose a tag** 输入 `v0.1.2`，点 **Create new tag: v0.1.2 on publish**（一定带 `v`）。
4. Title 填 `v0.1.2`；描述可填：
   `发行包：zip + tgz；修复安装说明；宠物运行时无变更。`
5. 点 **Publish release**。

**你应该看到**：Release 页面出现；Actions 里 `Release` 工作流转绿（约 1–3 分钟）；刷新后附件有
`dsh-klein-cat-pet-0.1.2.zip` 和 `dsh-klein-cat-pet-0.1.2.tgz` 两个文件。

## 4. 如果 Actions 失败

1. 打开 Actions 日志看红色报错，截图发回聊天。
2. 打开该 Release → **Edit release** → 把本地 `dist/` 里的 `.tgz`（和 `.zip`）拖到附件区 → **Update release**。
3. `.tgz` 是安装用的关键文件；`.zip` 只是手动解压备份。

## 5. 验证下载与安装

1. 在 Release 下载 `dsh-klein-cat-pet-0.1.2.tgz`（需要登录有权限的账号）。
2. DSH Desktop → 设置 → 插件 → 安装本地文件/路径，选这个 `.tgz`；装好后刷新。
3. 如果插件页不接受本地路径：按 README 的“手动兜底”——解压到 profile 的
   `node_modules\dsh-klein-cat-pet`，并把 `dsh-klein-cat-pet` 加进 profile `package.json` 的
   `dsh.profile.bundles`，再刷新。

**你应该看到**：插件页显示 `dsh-klein-cat-pet` 0.1.2；刷新后猫在，三态/音效正常。

## 6. 分享与公开（可选）

- 仓库是私有的：别人匿名打开 Release 仍是 404。最稳的是把 `.tgz` 文件直接发给朋友。
- 想公开下载：GitHub 仓库 → **Settings → General → Danger Zone → Change visibility → Public**；
  之后匿名 Release 和 `.tgz` 才能下载。这一步由你决定。

## 发布确认清单

- [ ] 本机刷新能看到猫和蓝色大鱼，三态/音效正常。
- [ ] GitHub Desktop 的 Changes 正好是上面 7 个文件。
- [ ] Commit + Push 成功。
- [ ] GitHub Release `v0.1.2` 已发布。
- [ ] Actions 绿色，Release 同时有 `.zip` 和 `.tgz`。
- [ ] 下载 `.tgz` 并在插件页安装成功，插件页显示 0.1.2。
- [ ] 刷新后猫在。

任何一项不符合，先停在这一步，把截图或报错发回聊天。
